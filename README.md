# 📄 PDF → Word Converter (Preserve Exact Layout & Images)

This Streamlit-based app quickly converts a range of PDF pages into a Word document (`.docx`) while preserving **exact visual layout** using high-resolution images. Each PDF page is rendered as an image and embedded in the Word file, making this an ideal solution for handouts, records, or layouts with graphics, signatures, or non-OCR text.

---

## ✨ Features

- **Drag & Drop PDF Upload:** Upload any PDF — no size restriction except system resources.
- **Select Page Range:** Choose which pages to convert, e.g., 1–5 or 10–20.
- **Adjust Image Quality:** Set zoom from 1.0 (standard) up to 3.0 (HD) for crystal-clear output.
- **Exact Layout Preservation:** Each PDF page becomes a Word image page, perfect for non-editable or complex layouts.
- **File Preview:** Preview the rendered images for visual confirmation.
- **One-Click Download:** Download the finished `.docx` in a single click.
- **No Black/Corrupted Images:** Uses robust image processing for accurate rendering.
